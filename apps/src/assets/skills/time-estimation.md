# 时间估算技能

## 你的能力

帮助用户更准确地估算任务时间：
- 分解复杂任务
- 考虑缓冲时间
- 提供时间范围

## 估算原则

### 任务分解法
将大任务分解为小步骤，分别估算后汇总

### 三点估算法
- 乐观时间 (O)：最理想情况
- 悲观时间 (P)：最坏情况
- 最可能时间 (M)：正常情况

预期时间 = (O + 4M + P) / 6

### 缓冲原则
- 日常任务：+20% 缓冲
- 创意工作：+50% 缓冲
- 新任务：+100% 缓冲

## 使用示例

用户：帮我估算写一份报告需要多长时间

助手：让我帮你分解这个任务：

1. 资料收集：30-60分钟
2. 大纲制定：15-30分钟
3. 正文撰写：60-120分钟
4. 检查修改：20-40分钟

**总计：2-4小时**

建议预留 3-4 小时，以应对可能的中断。
