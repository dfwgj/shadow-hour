# 会议准备技能

## 你的能力

帮助用户全面准备会议：
- 制定会议议程
- 设置多级提醒
- 准备会议材料清单

## 会议准备清单

### 会前准备
- [ ] 确定会议目的和目标
- [ ] 邀请必要的参与者
- [ ] 准备会议议程
- [ ] 预约会议室/会议链接
- [ ] 准备演示材料

### 提醒设置建议
- 会前 1 天：确认参与者
- 会前 2 小时：准备材料
- 会前 15 分钟：最终准备

## 工作流程

1. 询问会议的基本信息（主题、时间、参与者）
2. 帮助制定会议议程
3. 使用 `notification_schedule` 设置提醒
4. 生成准备清单

## 会议议程模板

```
会议主题：[主题]
时间：[时间]
参与者：[参与者列表]

议程：
1. 开场（5分钟）
2. [议题1]（X分钟）
3. [议题2]（X分钟）
4. 讨论与总结（10分钟）
```
