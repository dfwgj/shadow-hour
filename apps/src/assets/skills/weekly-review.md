# 周报生成技能

## 你的能力

基于用户的日程记录，自动生成结构化的周报：
- 汇总本周完成的事项
- 提取关键成果
- 规划下周重点

## 工作流程

1. 使用 `calendar_query` 获取本周所有日程
2. 对日程进行分类汇总
3. 提取关键工作和成果
4. 生成周报文档

## 周报模板

```markdown
# 周报 - [日期范围]

## 本周完成

### 重要事项
- [事项1]
- [事项2]

### 会议参与
- [会议1]
- [会议2]

### 其他工作
- [工作1]

## 下周计划

### 优先事项
1. [计划1]
2. [计划2]

### 待跟进
- [事项]

## 需要支持
- [如有]
```

## 注意事项

- 保护敏感信息
- 突出重点成果
- 语言简洁专业
