# Shadow Hour - 程序概要设计

## 一、系统概述

### 1.1 项目结构

本项目采用 **Monorepo** 架构，使用 pnpm + Turborepo 管理多个工作区包：

```
tcamp/
├── apps/                    # 主应用
│   └── shadow-hour/        # 移动应用主体
├── packages/               # 可复用包
│   ├── xierfloat-mobile-ai/    # AI Agent SDK
│   ├── http-stream/            # HTTP 流式客户端
│   └── xierfloat-mobile-ui/    # UI 组件库
├── docs/                   # 技术文档
└── scripts/                # 构建脚本
```

### 1.2 技术选型

| 层次 | 技术 | 版本 |
|------|------|------|
| 移动框架 | NativeScript | ^8.8.6 |
| UI 框架 | Vue 3 | ^3.5.22 |
| 语言 | TypeScript | ^5.9.3 |
| 样式 | TailwindCSS | ^3.4.3 |
| 构建 | Webpack / Turbo | ~5.0 / ^2.5 |
| 测试 | Vitest | ^3.2.4 |

| xierfloat-mobile-ui | 可复用 UI 组件（日历、Toast、卡片等） |

## 三、核心数据结构

### 3.1 日历事件 (CalendarEvent)

```typescript
interface CalendarEvent {
  uid: string                    // 唯一标识
  dtStart: Date                  // 开始时间
  dtEnd?: Date                   // 结束时间
  summary: string                // 事件标题
  description?: string           // 描述
  location?: string              // 地点
  status?: EventStatus           // 状态: TENTATIVE | CONFIRMED | CANCELLED
  rrule?: RecurrenceRule         // 重复规则
  alarms?: VAlarm[]              // 提醒列表
  categories?: string[]          // 分类标签
  lunar?: LunarDate              // 农历信息
}

interface RecurrenceRule {
  freq: 'DAILY' | 'WEEKLY' | 'MONTHLY' | 'YEARLY'
  interval?: number
  count?: number
  until?: Date
  byday?: string[]
}

interface VAlarm {
  action: 'DISPLAY' | 'AUDIO' | 'EMAIL'
  trigger: number                // 提前时间(分钟)
  description?: string
}
```

### 3.2 聊天消息 (ChatMessage)

```typescript
interface ChatMessage {
  id: string                     // 消息 ID

  toolUses?: ToolUse[]           // 工具调用列表
}

interface ToolUse {

```

```typescript
interface LLMConfig {
  id: string                     // 配置 ID
```

```typescript
interface LLMAdapter {
  // 属性
  readonly name: string
```

```typescript
interface ToolDefinition {

interface ToolResult {

  error?: string

interface ToolRegistry {
```

## 六、存储设计

### 6.1 本地存储方案

| 数据类型 | 存储方式 | 说明 |
|----------|----------|------|
| 日历事件 | SQLite | 结构化存储，支持复杂查询 |
| 聊天记录 | SQLite | 按会话组织，支持历史回溯 |
| 应用配置 | ApplicationSettings | Key-Value 存储 |
| API 密钥 | ApplicationSettings | 加密存储 |

### 6.2 数据库表结构

```sql
-- 日历事件表
CREATE TABLE calendar_events (
  uid TEXT PRIMARY KEY,
  summary TEXT NOT NULL,
  dt_start INTEGER NOT NULL,
  dt_end INTEGER,
  description TEXT,
  location TEXT,
  status TEXT DEFAULT 'CONFIRMED',
  rrule TEXT,
  alarms TEXT,
  created_at INTEGER,
  updated_at INTEGER
);

-- 聊天会话表
CREATE TABLE chat_sessions (
  id TEXT PRIMARY KEY,
  title TEXT,
  created_at INTEGER,
  updated_at INTEGER
);

-- 聊天消息表
CREATE TABLE chat_messages (
  id TEXT PRIMARY KEY,
  session_id TEXT,
  role TEXT NOT NULL,
  content TEXT,
  timestamp INTEGER,
  tool_uses TEXT,
  FOREIGN KEY (session_id) REFERENCES chat_sessions(id)
);
```

## 七、错误处理设计

### 7.1 错误分类

| 类型 | 处理方式 |
|------|----------|
| 网络错误 | Toast 提示 + 重试选项 |
| API 错误 | 显示错误信息 + 建议操作 |
| 工具执行错误 | 返回给 AI 处理 |
| 数据库错误 | 日志记录 + 降级处理 |

### 7.2 错误恢复机制

```typescript
// 流式请求错误恢复
async function callAPIWithRetry(input: string, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      await callSiliconFlowAPI(input)
      return
    } catch (error) {
      if (i === maxRetries - 1) throw error
      await delay(1000 * (i + 1))  // 指数退避
    }
  }
}
```

## 八、性能优化设计

### 8.1 渲染优化

- 虚拟滚动：长列表使用虚拟滚动
- 懒加载：非首屏组件延迟加载
- 缓存：日历数据按月缓存

### 8.2 网络优化

- 流式传输：AI 响应实时显示
- 请求合并：批量操作合并请求
- 超时控制：60秒超时 + 中断功能

### 8.3 存储优化

- 索引：关键字段建立索引
- 分页：历史记录分页加载
- 压缩：长文本内容压缩存储
