# Shadow Hour (影时) - 产品功能介绍

## 一、产品概述

**Shadow Hour (影时)** 是一款基于 NativeScript Vue3 开发的智能日程管理移动应用，内置 AI 助手「埃癸斯」，为用户提供智能化的日程管理体验。

### 产品定位

- **目标用户**：需要高效管理日程、希望借助 AI 提升效率的职场人士和学生
- **核心价值**：将传统日历功能与 AI 智能助手深度结合，通过自然语言交互管理日程
- **差异化优势**：原生性能 + AI 工具调用 + 角色化交互体验

---

## 二、核心功能模块

### 2.1 智能日历系统

#### 多视图展示

| 视图 | 功能描述 |
|------|----------|
| **年视图** | 全年概览，快速定位月份，显示各月事件密度 |
| **月视图** | 详细日期网格，事件卡片预览，支持农历显示 |
| **周视图** | 时间线布局，精确到小时的日程安排 |
| **日程视图** | 按时间顺序的事件列表，便于查看当日安排 |

#### 事件管理

- **创建事件**：标题、时间、地点、描述、提醒设置
- **重复规则**：支持每日/每周/每月/每年重复
- **提醒机制**：可设置多个提前提醒（5分钟至1周）
- **事件状态**：暂定/已确认/已取消
- **快速编辑**：点击事件卡片直接修改

#### 农历支持

- 自动显示农历日期
- 传统节日标注
- 可选开启/关闭

---

### 2.2 AI 助手「埃癸斯」

#### 角色设定

埃癸斯是来自《女神异闻录3》的 AI 角色，具有以下特点：
- 认真负责，对任务有强烈使命感
- 直接坦率，不会说谎
- 温暖关怀，会在完成任务后表达关心

#### 智能对话

- **流式响应**：实时显示 AI 回复，打字机效果
- **上下文理解**：保持对话连贯性，理解指代关系
- **多会话管理**：支持创建、切换、删除多个对话

#### 日程管理能力

通过自然语言指令管理日程：

```
用户：帮我安排明天下午3点的会议
埃癸斯：好的，我来为您安排。请问会议主题是什么？需要设置提醒吗？

用户：主题是项目评审，提前15分钟提醒
埃癸斯：明白了！已为您创建日程：
  📅 项目评审会议
  🕒 明天 15:00
  ⏰ 提前15分钟提醒
```

#### 支持的指令类型

| 类型 | 示例 |
|------|------|
| 查询日程 | "查看今天的安排"、"本周有什么会议" |
| 创建日程 | "明天上午10点开会"、"下周五安排聚餐" |
| 修改日程 | "把明天的会议改到后天" |
| 删除日程 | "取消周五的会议" |
| 批量操作 | "帮我安排下周的复习计划" |

#### 智能建议

- **日程优化**：分析日程密度，提供优化建议
- **会议准备**：生成会议议程和准备清单
- **周报生成**：根据日程自动生成周报
- **时间估算**：帮助估算任务所需时间

### 2.3 通知提醒系统

#### 本地通知

- 日程提前提醒
- 自定义提醒时间
- 支持多级提醒（如会前1天、2小时、15分钟）

#### AI 调度提醒

```
用户：提醒我明天早上9点吃药
埃癸斯：好的，已为您设置提醒：
  🔔 明天 09:00 - 吃药提醒
```

---

### 2.4 多模型支持

#### 支持的 AI 模型

| 提供商 | 模型 | 特点 |
|--------|------|------|
| OpenAI | GPT-4o | 视觉理解、工具调用 |
| Anthropic | Claude 3.5 | 长上下文、工具调用 |

#### 配置灵活

- 自定义 API Key
- 自定义 API 地址
- 模型参数调节（温度、最大 Token）

## 三、使用场景

### 场景一：日常工作管理

```
早晨查看：「今天有什么安排？」
会议安排：「下午2点和客户开会，地点在会议室A」
临时变更：「把3点的会议推迟半小时」
```

### 场景二：学习计划制定

```
制定计划：「帮我安排下周的期末复习计划」
查询进度：「这周完成了哪些复习任务」
调整安排：「把周四的英语复习和周五的数学复习交换」
```

### 场景三：生活事务提醒

```
设置提醒：「每天早上8点提醒我吃早餐」
周期事项：「每周日提醒我整理房间」
临时提醒：「30分钟后提醒我给妈妈打电话」
```

## 四、产品特色

### 4.1 原生性能

- 基于 NativeScript 直接调用原生 UI 组件
- 流畅的动画和交互体验
- 低内存占用，省电优化

### 4.2 隐私保护

- 数据本地存储（SQLite）
- 支持本地 AI 模型（Ollama）
- API Key 本地加密保存

### 4.3 角色化体验

- 独特的 AI 角色人设
- 温暖有温度的交互方式
- 知识库加持的专业回答

### 4.4 高度可定制

- 多种主题切换
- 午夜特殊主题
- 日历视图偏好设置
